# OctoHandy static preview

A static build of the public pages (home, Explore, My shelf) that runs without the backend or Clerk.
Pages switch with `#/explore` and `#/profile`; the chat answers in demo mode.

Open it with any static server, for example:

```
npx serve preview
```

The real app lives in `src/`; this folder is only a snapshot for showing the design.
